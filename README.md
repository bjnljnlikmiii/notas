# Tarea programada

Tarea personal que se ejecuta sola cada 20 minutos.

Configuración en **Settings → Secrets and variables → Actions**:

| Secreto | Valor |
|---|---|
| `TELEGRAM_TOKEN` | La clave de Telegram |
| `TELEGRAM_CHAT_ID` | Dónde avisar (número de chat o `@nombre` del canal) |

Los ajustes están en `.github/workflows/tarea.yml`.
